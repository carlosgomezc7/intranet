## Purpose

Provides virtual project workspaces (Project Hubs) and interest-based Communities of Practice to break functional silos in 200-employee organizations, enabling cross-disciplinary alignment, roadmap tracking, and collaborative knowledge sharing.

## ADDED Requirements

### Requirement: Cross-functional project hubs
The system SHALL support creating dedicated project workspaces with multi-department member rosters, shared roadmaps, key meeting agreements, and embedded task boards.

#### Scenario: Creating a cross-functional project workspace
- **WHEN** a project lead creates a Project Hub with members from Tecnología, Operaciones, and Finanzas
- **THEN** the system SHALL create a private workspace accessible to assigned members with shared timeline milestones, discussion threads, and document links

### Requirement: Thematic communities of practice
The system SHALL provide open and moderated community channels centered around strategic topics (Innovation, Continuous Improvement, Sustainability, Architecture).

#### Scenario: Joining a community of practice
- **WHEN** an employee browses the Communities directory and joins the "Innovación & IA" forum
- **THEN** the system SHALL add the community to the user's workspace list and enable posting, commenting, and reaction capabilities within the community feed
